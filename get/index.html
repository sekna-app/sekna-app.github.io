What is HEMERA?

HEMERA turns the media plan into a live dashboard. Every day it shows spend, conversions, conversion value and ROAS against the daily target, split by campaign type, with the projects and keywords behind them.

Follow the month day by day, compare any two months, see how the same Hijri day did in past years, and share any view to WhatsApp as a clean image. The same live numbers on Android, iPhone and your laptop.

The model behind the plan

How the Media Plan Works

The model builds the forecast through five key steps.

1
Base Performance

It analyzes the last 60 days and removes seasonal effects to estimate the account’s true Base Performance.

60 days
2
Month strength

It calculates the strength of the upcoming month using Hijri seasonality, weekday effects, week-of-month patterns, and special days.

Hijri calendar
3
Forecast

It forecasts Spend, Revenue, and Conversions, using a 0.7 elasticity factor to reflect that increasing budget does not increase results at the same rate.

0.7 elasticity
4
Recommended Budget

It sets the Recommended Budget by combining 50% of the model forecast + 50% of performance from the same Hijri days last year.

50% + 50%
5
Daily plan

It then distributes the plan daily, weekly, and across channels based on period strength and channel efficiency.

Day · week · channel

We tested 5 different planning scenarios, along with multiple model settings, using a blind backtest. This setup delivered the strongest overall accuracy for forecasting Spend, Revenue, and Conversions, so it was selected as the final media planning model.
