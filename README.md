# SEKNA

The SEKNA web app: **https://sekna-app.github.io**

It shows the same live dashboard as the SEKNA Android app. The page is a static
build of the dashboard; data, sign-in and admin actions come from the SEKNA
Apps Script server. No data or credentials are stored in this repository.

## Install as an app
- **iPhone / iPad (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** menu ⋮ → Install app.
- **Windows / Mac (Chrome or Edge):** the install icon in the address bar.

## Custom domain (later)
Add a `CNAME` file with the domain (for example `app.sekna.co.uk`), point the
domain's DNS to GitHub Pages, then set it under Settings → Pages.
